# Sushi LM — Restaurante Japonês

Landing page de alta conversão e experiência cinematográfica para o **Sushi LM**, tradicional restaurante japonês de rodízio localizado em Rudge Ramos, São Bernardo do Campo - SP.

## 🍣 O Projeto
- **Conceito Diretor:** FARTURA (Mesa cheia, peixe fresco cortado na hora, custo-benefício comprovado pelos clientes).
- **Stack:** Vanilla HTML5, CSS3 avançado, Vanilla JavaScript ES6+ (zero dependências, sem framework ou build step).
- **Performance & Efeitos:**
  - Hero scroll pinned em 250vh com motor de interpolação dt-normalizado (K=0.10) e física de desaceleração.
  - Galeria horizontal por virtual scroll com momentum decay de 0.90 por frame via `transform: translateX`.
  - Ritual interativo "Mesa sem Fim" permitindo simular rodadas ilimitadas.
  - A11y completa (Skip link, navegação mobile por drawer com suporte a tecla Escape, contraste >= 4.5:1, prefers-reduced-motion respeitado).
  - SEO com metatags Open Graph e Schema.org LocalBusiness (JSON-LD).
